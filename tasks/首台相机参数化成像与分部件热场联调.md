## 一、本轮必须实际实现什么

复用已恢复的数值红外链和 Avata 2 生产副本，建立 CAM01 来源化参数配置，使分部件外表面温度进入辐射链，并完成原生分辨率的少量数值诊断与 RGB/IR 对齐输出。

不是再写一份方案就结束，也不是等真实设备资料齐全才写代码。实测身份/响应缺失时，允许有依据、明确披露的参数化模型；结果最高为 SIM2_PARAMETERIZED_UNCALIBRATED。

变量：IR_ROOT 为 AGENTS.md 中已确认数值工程；ASSET_ROOT 为已确认资产库；TASK_ROOT=IR_ROOT/lanes/worker-physics/workspace/首台相机参数化联调。

读取本轮用户提供的交接资料、原技术方案和非公开的 CAM01 参数附录/候选配置。先找本地已知资料位置和项目引用，不能扫描无关私人资料。若原文暂时不在本地，可使用本轮已核验附录并标 DERIVED_FROM_REVIEWED_SOURCE，不得谎报亲自读取原文；只有交接稿而无原文/已核验附录时，参数只能标 SECONDARY_REPORT，不能升格为官方或实测。

## 五、CAM01 参数配置与一致性校验

生成《首台相机参数配置.yaml》和《参数来源与冲突.md》，至少包括：探测器技术/波段、原生尺寸/像元、焦距和视场、帧率、热时间常数、读出积分、光学透过率/光圈、RSR/PSF、噪声、ADC、NUC/坏点/显示处理、RAW 可获取性、观测平台与标定范围。

每个量保存 source_value / effective_value / unit / evidence_type / source_locator / uncertainty / conflict / assumed_for_run。使用 null 表示未知；不能用 0 伪装未知。

执行：
1. 按原生像元与焦距计算近轴视场，原文视场单独保留；不同时把相互不一致的量设为硬约束。
2. 依据详参附录选广角、中间、长焦三配置；中间值是测试选择，不写成厂商档位。
3. 帧间隔从帧率导出，但不当曝光。微测辐射热计的热惯性、ROIC 积分/采样和数字时域滤波分开；未知值用显式假设和敏感性分支，不借用别家设备数值当真值。
4. NETD 与参考温度/光圈/处理阶段一起记录；通过所选响应的温度导数换算等效辐射或 DN 噪声，明确所处物理域，避免与 FPN/读噪声重复叠加。
5. 内部 ADC、模拟高位深 DN、外部处理输出和显示预览分别保存。真实 RAW/AGC/NUC 细节未知时保持未知；可实现明确命名的理想或假设模块，不假称厂家算法。

## 六、分部件热场真正进入图像

对 Avata 2 能辨认的外表面建立稳定 surface_region_id，包括机身壳、电机外表面、护桨/旋翼和相机/载荷可见区；内部电池、电调等可以用等效节点，但没有来源不能捏造真实位置/尺寸。未覆盖表面使用声明过的 fallback 并统计比例。

建立 thermal_node_id -> surface_region_id -> 几何命中/材质口的映射。各表面用同一时刻的温度、发射率和可见性进入原辐射模块；不能最后把整机仍折算成单个 body_shell 温度。

保留均温回归开关。至少检查：全区同温时退化到既有均温结果；只改一个区温度时，前光学辐射变化局限于其可见区域；经 PSF 扩展后的变化符合核支持而非整机无差别变化；遮挡的内部热源不直接出现在图像中。

热网络测试：无输入平衡、已知损耗下能量账、升温/冷却、时间步长收敛。机体、旋翼、热状态共享时钟与完整历史缓存。不要让每段短视频从不同随意初温重启，也不要把电池输出总功率都算为电池热量。本轮不承诺真实温升复现。

## 七、成像链的最小实现

复用可用模块，补足可测试接口：表面辐射/反射 -> 大气传输与路径贡献 -> 光学 PSF -> 探测器时间响应与像元采样 -> 随机/固定噪声 -> 模拟量化 -> 显式校正/显示分支。

模块必须声明单位、输入/输出域、顺序和近似。不双算像元孔径、PSF、光学透过率和噪声。RSR 或传输曲线未知时可采用显式假设函数，单列敏感性测试；不把带内矩形响应或高斯 PSF 说成实机测量。

固定图样和坏点图按 sensor_instance/会话生成并跨帧稳定；逐帧噪声单独种子；噪声种子不得由类别决定。校正残差、NUC 事件与显示处理都记录状态。

RGB 保留同场景时间和明确内外参；RGB 相机未标定时标 DIAGNOSTIC_RGB，不宣称已复现双通道实机融合设备。

## 八、先原生单帧，再最多三十帧

先复跑小窗回归，再执行原生分辨率单帧。不能把旧低分辨率图放大充数。采用分块/BVH/缓存等已有或可验证优化；ROI 必须保留原生内参、裁剪偏移和 PSF 边界，并与全帧对应区域对照。

预检登记本机内存/显存、单帧时限与总预算。默认单进程；默认单帧墙钟上限 15 分钟、整批上限 60 分钟、内存安全预算不超过预检可用量的 60%，既有更严格限制优先。超限保存诊断并停止，不自动降低数值门槛、修改分辨率标签或无限后台运行。

单帧通过后，三档焦距各取一个连续八帧片段，另各取一帧无目标和一帧完全遮挡，最多三十组。时间步为配置的原生帧周期；不同焦距的世界状态/时刻保持可比。长时热历史可离线积分并缓存，不需要渲染全部预热帧。

先使用单一可控背景和一个已核验资产。采样收敛不满足时标 rejected；完全遮挡按原规则 ignore，不能改成无目标。旧亚像素失败仍保留，新诊断独立记录。

## 九、数据合同与防泄漏框架

保存 L0 物理中间量、模拟传感器层、任务图像/标签与预览；物理中间量不能仅保存显示图。真实来源只有处理后低位深时，不虚构高位深母数据。

每帧记录 asset/version、相机配置版本、场景/轨迹/采集家族、时间、机体和旋翼状态、表面温度/材料、辐射和 DN、显示处理、无遮挡/可见掩膜、框、像素尺度定义、配置及软件哈希。

实现外生变量和物理派生变量的分列检查、分组切分、类相关配置/种子检查、跨 split 家族重叠检查。反事实家族不得拆分。观察框尺寸和制作质量不能混作无条件泄漏判据。

构造少量人工元数据正/负对照，仅测试审计能否发现注入的背景/种子泄漏；这不是多机型科研数据。单机样本上的多类别统计审计写 NOT_APPLICABLE，不能写 LEAKAGE_FREE。为未来主随机、反事实、未知背景数据保留协议，不在本轮扩量或训练比赛模型。
